# Copenhagen — a collage in notes

An interactive collage by Fonda, with linked image regions and a scrolling annotation panel.

Published at https://fonduh.github.io/copenhagen-collage/ using GitHub Pages from the main branch root.

Hover or tap a highlighted image region to read a note. Choose a note to find its place in the collage. Add a note by drawing a box around a detail, then entering a caption.

Annotation edits are stored in the current browser only. Download and import notes to back up or transfer them. To change the default annotations for everyone, update DEFAULT_NOTES in app.js and push to main.

The site is static HTML, CSS, and JavaScript with responsive WebP images. No build step is required. Serve this directory with any static HTTP server for local preview.
